# Deception-Resistant Presence Proof (DRPP) Research Implementation

This repository contains the full computational research pipeline for the paper:
**"Deception-Resistant Presence Proof: A Cryptographic Protocol for Human-Centric Authentication"**

## Overview
This repository covers:
1. Cryptographic protocol simulation (DRPP, traditional, collusion attacks)
2. Game-based security proof verification (PRF-based reduction)
3. Statistical analysis and result reproduction
4. Publication-ready figure and table generation

## Setup
1. Create a virtual environment.
2. Install dependencies:
   `pip install -r requirements.txt`

## Running Experiments
To run the full suite of experiments, execute:
`python experiments/run_all.py`

This will generate the required outputs in the `outputs/` directory.
