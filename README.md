# Temporal Leakage in Insider-Threat Evaluation: A Chronological Protocol and Audit on the LANL Red-Team Data

This repository contains a leakage-aware chronological evaluation of the LANL cyber-security dataset. The study aims to present the work as a temporal-leakage / evaluation-methodology study, and explicitly NOT as a validated insider-threat detector.

**Note:** The LANL red-team events are authentication events from one organisation's red-team exercise; they are not insider behaviour.
