# Early-Stage Anomaly Detection and Downtime Risk Scoring in Cloud-Integrated Industrial Sensors

This repository contains an end-to-end Machine Learning pipeline designed for early-stage anomaly detection and downtime risk scoring in cloud-integrated industrial sensors.

## Setup Instructions

1. Install Python 3.10+
2. Install dependencies:
   `pip install pandas numpy scikit-learn xgboost matplotlib seaborn scipy tensorflow kagglehub`
3. Run the complete pipeline script:
   `python pipeline.py`

## Deliverables

- `pipeline.py` — full end-to-end script
- `eda_report.ipynb` — exploratory analysis notebook
- `models/` — saved trained models
- `outputs/figures/` — all 51 figures, PNG, 300dpi
- `outputs/` — classification reports and risk score CSVs
- `README.md` — how to run the pipeline
