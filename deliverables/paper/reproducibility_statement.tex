\section*{Reproducibility Statement}
The data used in this study is the official LANL "Comprehensive, Multi-Source Cyber-Security Events" dataset, accessible at \url{https://csr.lanl.gov/data/cyber1/}. Complete provenance including file SHA-256 hashes, exact sampling seeds, and library versions are stored in \texttt{outputs/provenance.json}. The full reproducible pipeline can be executed via a single entrypoint script.
