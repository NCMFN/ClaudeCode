\begin{abstract}
Detecting insider threats using authentication logs is a challenging task due to extreme class imbalance and shifting temporal dynamics. Prior works evaluating machine learning models on the LANL cyber-security dataset frequently report near-perfect detection metrics. In this methodological audit, we demonstrate that such performance is often an artefact of time-correlated sampling rather than genuine detection capability. When benign events are sampled from the beginning of the timeline while malicious red-team events are spread across later days, models spuriously learn temporal markers (e.g., hour of the day) to separate the classes. We propose a leakage-aware chronological protocol incorporating causal feature engineering, a strict purge gap between training and testing blocks, and block-bootstrap confidence intervals. We highlight the fragility of evaluation metrics in insider-threat detection and provide a robust framework for future audits.
\end{abstract}
