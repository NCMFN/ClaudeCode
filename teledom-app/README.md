# Teledom App

This is a Vite + React + TypeScript + Tailwind project representing a responsive, modern corporate website for an IT and Telecommunications company.

## Setup Instructions

1. **Install dependencies:**
   `npm install`

2. **Run development server:**
   `npm run dev &`

3. **Build for production:**
   `npm run build`

## Features
- Fully responsive layout with a mobile hamburger menu.
- Sticky header with shadow-on-scroll.
- Keyboard and hover accessible dropdown menus.
- Interactive carousels for testimonials and logos.
- Interactive tabs on solution detail pages.
- Centralized data management in `src/data/`.
- Accessible and semantic HTML elements.
- Basic SEO implemented with `react-helmet-async`.
